# Wall Rally

Flame と Forge2D を使った、一人用の2次元壁打ちテーブルテニスゲームです。ラケットでボールを打ち返し、できるだけ長くラリーを続けます。

## 遊び方

- `A` / `D` または左右矢印キー: ラケットを移動
- マウス移動: ポインターへラケットを移動
- タッチドラッグ: ラケットを移動
- `Space` またはタップ: サーブ
- `R` またはタップ: ゲームオーバー後にリスタート

連続リターン数に応じて得点が増え、5回ごとにボールが速くなります。ボールを3回落とすとゲームオーバーです。

## 実行

```sh
flutter pub get
flutter run -d chrome
```

ゲームルールのテストは `flutter test` で実行できます。
